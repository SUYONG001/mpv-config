## 一、 核心架构特性

### 1. uosc 与 ModernX 共存架构分工
为了解决两大主流 UI 框架界面重叠与功能冲突的问题，本方案实施了严格的视觉与职能解耦：

* **ModernX（`modernx.lua`）—— 专职主界面与交互渲染**：
  * 全权负责底部进度条、悬浮控制栏、顶部标题栏的视觉呈现。
  * 深度联动 `thumbfast.lua` 抓取进度条预览缩略图。
  * 接管播放器空闲时的 Logo 展示与纯音频状态指示。
* **uosc 框架 —— 专职功能菜单与辅助指示引擎**：
  * 全权负责鼠标右键与 <kbd>Tab</kbd> 唤出的多级半透明上下文菜单。
  * 提供播放列表导航面板、音轨/字幕直选面板与章节跳转列表。
  * **精准元素保留**：通过 `uosc.conf` 仅保留无边框细线边框（`window_border`）、右侧垂直音量滑块（`volume`）、流媒体缓冲旋转动画（`buffering_indicator`）及暂停闪烁图标（`pause_indicator`）。
  * **精准元素剔除**：强制禁用顶栏（`top_bar`）、进度条（`timeline`）、控制栏（`controls`）、空闲图标（`idle_indicator`）与音频指示（`audio_indicator`），彻底杜绝与 ModernX 发生视觉冲突。

> **实机效果预览 · 视频播放协同**：中部为鼠标右键唤出的 **uosc 半透明深色菜单**（支持倍速、轨道、滤镜快速直选），底部为 **ModernX 罗兰电竞紫进度条与控制栏**，鼠标悬停在时间轴上时，由 **Thumbfast** 秒级拉起高清原画缩略图，整体界面清爽无重叠。

### 2. Auto Profiles 分辨率区间自适应
抛弃脆弱的文件路径正则匹配，全面采用原生视频分辨率进行精准分流：
* **中等分辨率区间（`720P ≤ height < 2160`）**：自动激活 2 轮强效去色带（Deband），彻底抚平动画雾面与暗部渐变断层。
* **超高清区间（`width ≥ 2560`）**：自动关闭去色带，完整保留 2K/4K 原盘高码率原生胶片颗粒与皮肤细节。
* **低清老旧视频（`height ≤ 720`）**：自动提升抗振铃（Anti-ringing）系数至 `0.8`，有效压制压缩杂讯与边缘光晕。

## 二、 部署与还原步骤

### 1. 下载主程序并解压
* 从 SourceForge 官方构建源获取最新的 64 位构建包：  
  `https://sourceforge.net/projects/mpv-player-windows/files/64bit-v3/`
* 将下载的压缩包解压至本地安装目录（推荐路径：`D:\Data\Player\mpv\`）。

### 2. 导入便携配置文件
* 将本仓库的全部配置文件与文件夹放入 mpv 根目录下的 `portable_config` 目录中。
* 确保 `portable_config` 包含 `mpv.conf`、`input.conf`、`fonts/`、`scripts/` 以及 `script-opts/`。

### 3. 校验并修正 `thumbfast.conf`（关键步骤）
由于缩略图依赖后台静默调用 mpv 进程，换电脑或修改安装路径后必须核实该项：
* 打开 `portable_config\script-opts\thumbfast.conf`。
* 确认 `mpv_path=` 指向当前设备上的实际绝对路径，或者配置为自动检测：
  ```ini
  mpv_path=D:\Data\Player\mpv\mpv.exe
  # 或直接填写：mpv_path=mpv
  ```

### 4. （可选）关联文件格式
* 以管理员身份运行 mpv 目录下的 `mpv-register.bat` 即可一键绑定系统常见媒体格式。
* 若不绑定，亦可直接将视频文件拖入 `mpv.exe` 窗口播放。

## 三、 功能上线验证清单

完成部署后，拖拽任意测试视频进入播放器，依次核对以下状态：

* [ ] **画质与渲染**：按 <kbd>i</kbd> 开启性能面板，观察 `Dropped Frames`（丢帧数）为 0 或维持极低水准。
* [ ] **显卡策略**：已在显卡控制面板中将 `mpv.exe` 设定为“首选最高性能”与“固定刷新率”。
* [ ] **主界面弹出**：鼠标滑动至窗口底部，ModernX 罗兰紫进度条顺畅上浮弹出。
* [ ] **缩略图预览**：光标在进度条上方任意滑动，悬停位置的缩略图能够秒级渲染且无报错弹窗。
* [ ] **uosc 悬浮菜单**：点击鼠标右键或按 <kbd>Tab</kbd> 键，半透明菜单正常展示且文字为简体中文。

* [ ] **动态 Profile 触发**：
  * 播放 1080P 片源时，按 <kbd>Shift</kbd> + <kbd>i</kbd> 切至第 4 页可观察到 `Mid-Resolution-Deband` 预设处于激活状态。
  * 播放 4K 原盘片源时，去色带自动关闭。
* [ ] **纯音频播放专项**：
  * 播放 `.flac`、`.mp3` 等音频时，视频插值与升频后处理滤镜全自动注销卸载。
  * 音轨带有封面则居中展现封面，无封面则自动渲染彩虹色 CQT 频谱

## 五、 配置文件职能速查

| 配置文件 | 相对路径 | 核心管理职责 |
| :--- | :--- | :--- |
| **`mpv.conf`** | `portable_config/` | 视频输出核心、D3D11 渲染驱动、升降频算法与分辨率 Profile 条件触发器 |
| **`input.conf`** | `portable_config/` | 键盘鼠标按键映射、uosc 菜单绑定与隐藏命令集 |
| **`osc.conf`** | `script-opts/` | ModernX 界面尺寸、滑动动画、按钮逻辑与十六进制 BGR 进度条色库 |
| **`uosc.conf`** | `script-opts/` | uosc 右键菜单外观、多语言配置、元素屏蔽黑名单（`disable_elements`） |
| **`thumbfast.conf`** | `script-opts/` | 缩略图生成上限尺寸、静默调用进程绑定及网络流媒体缩略图开关 |
| **`visualizer.conf`** | `script-opts/` | 音频可视化类型选择、渲染画质分级、高度占比与启用条件 |
| **`volume_fix.conf`** | `script-opts/` | 视频与音频独立音量初值设定、纯音频模式封面渲染上限尺寸 |
| **`stats.conf`** | `script-opts/` | 性能统计面板悬浮停留时间及避让 uosc 顶栏的边距控制 |
| **`autoload.conf`** | `script-opts/` | 目录递归深度、连播媒体格式白名单与文件隐藏过滤规则 |

## 六、 进度条主题色库（BGR 格式）

ModernX 界面颜色遵循 **BGR（蓝-绿-红）** 排序，与传统 Web 端的 RGB 完全相反（例如网页 RGB 紫色 `#9933FF` 在配置中须转换为 `FF3399`）。

若需更换主题色，只需编辑 `portable_config/script-opts/osc.conf`，将末尾的 `seekbarfgcolor=` 改为下列代码即可：

| 分类系列 | 主题色彩名称 | BGR 配置代码 | 视觉效果描述 |
| :--- | :--- | :---: | :--- |
| **经典极客系** | 极简纯白 | `FFFFFF` | 纯净高亮，适合极简无干扰观影 |
| | 油管正红 | `0000FF` | 醒目鲜明，经典流媒体风格 |
| | 深海湛蓝 | `FF0000` | 沉稳冷峻，夜间使用不刺眼 |
| | 暖阳金橙 | `00B3FF` | 温和舒适，视觉辨识度高 |
| **动漫主题系** | 哔哩粉 | `9972FB` | 柔和粉红，二次元观影首选 |
| | 初音绿 | `BBC539` | 标志性葱绿配色，活力醒目 |
| | 初号机紫 | `A95178` | 沉稳微暗的经典机体配色 |

## 七、 跨平台与日常维护指南

1. **跨系统部署与平台微调**：
   * **Windows 平台**：强制保留 `gpu-api=d3d11` 以获得最佳的资源开销与流畅度。
   * **macOS / Linux 平台**：在 `mpv.conf` 中将 `gpu-api=d3d11` 改为 `gpu-api=vulkan` 或直接注释该行。
   * **脚本通用性**：内置的 5 份核心 Lua 脚本均为标准跨平台实现，无需更动内部代码。
2. **驱动更新维护**：
   * 每次显卡驱动重装或更新后，建议进入显卡控制面板重新确认 `mpv.exe` 是否维持“固定刷新”与“最高性能优先”策略。
3. **软解与硬解按需切换**：
   * 默认开启兼容性最高、色彩还原最准的软解（`hwdec=no`）。
   * 若播放超高码率 4K/8K 出现卡顿，可编辑 `mpv.conf` 将其修改为 `hwdec=nvdec` 或 `hwdec=auto-safe` 切换为显卡硬解码。
4. **版本迭代备份建议**：
   * 后续针对快捷键或滤镜进行优化后，建议将整个 `portable_config` 目录使用 7-Zip 重新打包存档，并同步更新文档日期与版本号。
